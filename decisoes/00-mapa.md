# Mapa das decisões

Cada bifurcação tem um arquivo. A história principal para e aponta para aqui.

```
Alba (história 01)
        │
        ▼
   Emboscada (02)
        │
        ├─ perseguem ──────────────► senda e caverna (03 em diante)
        │                                    │
        │                                    ├─ sigilo na boca
        │                                    ├─ alerta na boca
        │                                    ├─ chegam a tempo → Sera viva
        │                                    ├─ relógio a 0 → Sera morta
        │                                    └─ Yeemik oferece trégua
        │                                              │
        │                                              ├─ aceitam → Klarg primeiro (−2)
        │                                              └─ recusam → ele dispara
        │
        └─ abandonam e vão a Phandalin ► prisão, fuga, estrada
```

| Decisão | Arquivo | O que muda |
|---|---|---|
| Perseguir ou abandonar | [01](01-perseguir-ou-abandonar.md) | Caverna, ou cadeia |
| Sigilo ou alerta | [02](02-sigilo-ou-alerta.md) | Lámina da boca e se os vigias disparam |
| Viva ou morta | [03](03-relogio-viva-ou-morta.md) | Lámina do poste e o tom do final |
| Trato de Yeemik | [04](04-trato-yeemik.md) | −2 marcas, ou ele dispara |
| Prisão | [05](05-prisao-phandalin.md) | História alternativa inteira |

A história principal não se mistura com a prisão. Se entraram na vila sem a Sera e sem as caixas, fecha a pasta `historia-principal` e fica só no arquivo 05.
